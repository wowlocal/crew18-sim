# Crew 18 — iOS Simulator Review

Сервер для ревью iOS-игр в браузере на Mac mini: Tapflow 0.20.1,
выделенный iOS Simulator и стартовая игра **Podlodka Dive**.

Участники делают форк, собирают приложение для симулятора и передают ZIP.
Несколько ревьюеров по очереди запускают сборки на общем симуляторе через браузер.
Для такого сценария не нужно поднимать 100 симуляторов.

## Ревью

1. Откройте [локальный Tapflow](http://localhost:4000).
2. Загрузите `.app.zip` через **Upload build**, укажите участника и коммит в названии.
3. Выберите сборку → **Start QA** → Mac → **Podlodka Review**.
4. При необходимости нажмите **Launch app** в панели симулятора.

Сервер пока доступен только на самом Mac. Внешний доступ и аккаунты ревьюеров
настроим отдельно. [Установка и управление сервером](docs/remote-review.md).

## Собрать игру

Откройте `PodlodkaDive.xcodeproj` в Xcode, выберите iPhone Simulator и нажмите `⌘R`.
Для загрузки в Tapflow:

```sh
./scripts/build-review.sh
```

Архив появится в `build/review/PodlodkaDive.app.zip`.
Это сборка для iOS Simulator без подписи для распространения, не `.ipa` для iPhone.

Podlodka Dive — игра на SwiftUI с подводной физикой. Удерживайте экран,
чтобы всплывать, отпускайте, чтобы погружаться. Кнопка сверху ставит игру на паузу.
Лучший результат сохраняется через `UserDefaults`. Минимальная версия — iOS 17,
внешних зависимостей у игры нет.

## Состав репозитория

- `PodlodkaDive/`, `PodlodkaDiveTests/`, `PodlodkaDive.xcodeproj/` — исходники игры и тесты.
- `PodlodkaDive-Dactyl.swift` — отдельная версия исходника для Dactyl.
- `.tapflow-host/` — закреплённые npm-зависимости, конфигурация и запуск Tapflow.
- `scripts/` — сборка игры, установка LaunchAgent и управление сервером.
- `docs/remote-review.md` — настройка Mac и порядок ревью.

Пароли, база, загруженные сборки, логи и `node_modules` исключены из Git.
